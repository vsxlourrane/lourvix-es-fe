01 · Memoria Activa

Flashcards · Expresiones Argentinas

Haz clic en cada carta para virar y ver la traducción y el contexto. Expresiones de Argentina para el día a día profesional.

Argentina · Apertura Che → clic para ver significado
“cara”, “olha”, “viu”

La palabra más clásica de Argentina. Usada para llamar la atención de un colega o iniciar una frase.

«¿Che, miraste el Pull Request que te mandé?»

Argentina · Informal Boludo → clic para ver significado
“cara”, “mano”

Entre colegas con mucha intimidad y nivel horizontal. Cuidado: en ambientes formales o con gestores puede sonar irrespetuoso.

«Dale, boludo, aprobame el PR así mergeamos.»

Argentina · Confirmación Posta / ¿Es posta? → clic para ver significado
“verdad” / “¿es en serio?”

Se usa para confirmar que algo es verdad o para expresar sorpresa ante una situación.

«¿Posta que se cayó el servidor de base de datos?»

Argentina · Cultura Tomar un mate → clic para ver significado
“tomar um cafezinho”

O equivalente ao “cafezinho” no Brasil. Se alguém te convidar para tomar un mate, é o momento de descontrair, falar do projeto de forma informal ou alinhar alguma arquitetura.

«Che, ¿tomamos un mate y repasamos el diseño del microservicio?»

Argentina · Performance Tunar → clic para ver significado
refinar / otimizar

Adaptado del inglés to tune. Significa refinar y optimizar procesos.

«Hay que tunar esta query de Hibernate porque está matando la base del banco.»

Argentina · Performance Limar → clic para ver significado
polir / reduzir ao máximo

Expressão portenha para reduzir ao máximo, polir ou detalhar algo minuciosamente até a perfeição.

«Vamos a limar unos milisegundos en el procesamiento del batch.»

Argentina · Falha Pincharse / Romperse → clic para ver significado
falhar / quebrar

Usado quando o código ou o servidor falha (muda de estado ou cai devido a um erro, como um OutOfMemoryError em Java).

«Se pinchó el microservicio de transferencias por la cantidad de hilos nativos.»

Argentina · API Escupir → clic para ver significado
retornar rapidamente / emitir

Usado no sentido de retornar dados rapidamente ou emitir logs.

«El endpoint tiene que escupir el JSON del saldo en menos de 50ms.»

Argentina · Java Stremear → clic para ver significado
manipular fluxos de dados

Muito comum ao usar a API de Streams do Java moderno para processamento de coleções bancárias.

«Podés stremear la lista de transacciones para filtrar las que son fraudulentas.»

Argentina · Spring Inyectar → clic para ver significado
injetar (dependências)

Referência direta à injeção de dependências (Spring Framework / CDI).

«Fijate de inyectar bien el service en el controller.»

Argentina · Git Mergear / Pushear / Commitear → clic para ver significado
mergear / pushar / commitar

Aportunhações indispensáveis para o controle de versão com Git.

«¿Ya mergeaste las optimizaciones a main?»

Argentina · Foco Ponerse las pilas → clic para ver significado
focar / se esforçar

Expressão clássica que significa focar, colocar energia e resolver um problema difícil de forma ágil.

«Che, hay que ponerse las pilas con los tests unitarios antes del deploy.»

Argentina · Falha / distração Colgarse → clic para ver significado
travar / esquecer de responder

Ficar travado, esquecer de responder ou perder o foco (aplica-se tanto ao sistema travado quanto ao desenvolvedor distraído).

«Se colgó el servidor de testing» / «Disculpá, me colgué y no vi tu Pull Request».

Argentina · Reunião Chamuyar → clic para ver significado
enrolar / dar desculpas

No ambiente técnico de Buenos Aires, descreve a ação de “enrolar” em reuniões diárias (dailies) quando uma tarefa não avançou ou dar uma explicação superficial ao Product Owner.

«No avancé nada con el refactor, mañana veo qué le chamuyo ao Scrum Master.»

07 · Atención Crítica

Situación hipotética: tu cerebro en tensión real

El reloj marcaba las diez de la mañana cuando Fernando se conectó a la videollamada. Del otro lado, el equipo de Buenos Aires revisaba los logs del microservicio de transferencias.

Martín · Líder técnico —Che, Fernando, se pinchó el servicio de pagos después del último deploy. El endpoint tiene que escupir el JSON del saldo en menos de 50 ms, pero está demorando 200 ms.

Fernando respiró hondo. Sabía que tenía que tunar la query de Hibernate y limar unos milisegundos en el procesamiento del batch.

Fernando —Mirá, el problema está en cómo el framework gestiona el pool de conexiones. Podés stremear la lista de transacciones para filtrar las fraudulentas y así mitigar la carga.
Arquitecto —¿Y qué proponés? No me cierra la idea de meter un parche ahora.
Fernando —No es un parche. Propongo inyectar bien el service en el controller, mergear las optimizaciones a main y pushear el cambio. Si implementás esto, destrabás el flujo de transacciones y el backend rinde mejor bajo alta carga.
Martín —Dale, hacelo. Pero ponete las pilas con los tests unitarios antes del deploy. No te cuelgues como la última vez.
Fernando —Tranquilo, no me voy a chamuyar. Ya tengo el presupuesto listo y voy a relevar los datos del servidor para ver dónde se frena el proceso.

08 · Léxico verbal

10 verbos de reunión en voseo

Verbos que aparecen en cada reunión con Buenos Aires. A la izquierda, el infinitivo y su significado en el contexto financiero/técnico. Al centro, las dos formas que vos vas a escuchar y a usar. A la derecha, un ejemplo real de la narrativa o del día a día.

Regla rápida: Presente → acento en la última sílaba: -ás / -és / -ís. Imperativo → quitar la -r del infinitivo: hablar → hablá, comer → comé, vivir → viví.
Verbo · significado Presente · vos Imperativo · vos Ejemplo en contexto
DestrabarSolucionar un cuello de botella (gargalo) Vos destrabás Destrabá vos «Si optimizamos este microservicio, destrabás el flujo de transacciones.»
AnalizarEvaluar métricas o flujos financieros Vos analizás Analizá vos «Necesito que analizás el cuello de botella en la pasarela de pagos.»
PresupuestarCalcular costos de implementación Vos presupuestás Presupuestá vos «Por favor, presupuestá la infraestructura para el nuevo módulo.»
ImplementarDesplegar código o soluciones Vos implementás Implementá vos «Cuando implementás este cambio, el flujo administrativo mejora.»
DecidirTomar determinaciones de negocio Vos decidís Decidí vos «Vos decidís si aprobamos este flujo o si mitigamos el riesgo antes.»
MitigarReducir riesgos financieros o fallas Vos mitigás Mitigá vos «Con esta validación, mitigás las pérdidas por duplicidad.»
LiquidarProcesar pagos o cerrar cuentas Vos liquidás Liquidá vos «Asegurate de cómo liquidás las órdenes pendientes al final del día.»
RelevarLevantar requerimientos o información Vos relevás Relevá vos «Relevá los datos del servidor para ver dónde se frena el proceso.»
DemorarRetrasar (tiempo de respuesta / latency) Vos demorás Demorá vos «Si demorás la confirmación, el sistema financiero cancela el flujo.»
RendirDar rendimiento / Dar cuentas de gastos Vos rendís Rendí vos «Este backend rinde mejor bajo alta carga de peticiones.»
